# AI Agents Ottawa: talk proposals

Want to speak at [AI Agents Ottawa](https://www.meetup.com/ai-agents-ottawa/)? [Propose a talk](https://github.com/ai-agents-ottawa/talks/issues/new?template=talk-proposal.yml).

Each night has two talks of 20 to 30 minutes: one on AI in everyday life, and one for developers. Demos beat slides, and first-timers are welcome.

Proposals here are public. No GitHub account? Post in #speakers on our [Discord](https://discord.gg/8T5hUhN4d5).
